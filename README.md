# BITDB — Tabla ASCII Interactiva

**BITDB** es una [tabla ASCII interactiva](https://eldiablo45.github.io/RadixRef/) completa (0–255): buscador por letra, símbolo o código, preview con valores en decimal, hexadecimal, octal y binario, entidad HTML y diagrama de bits, más conversores entre bases sincronizados en vivo.

- ✅ ASCII 0–127 + extendido 128–255 con nombres en español e inglés
- 🔍 Búsqueda instantánea con ranking (código exacto primero)
- 📋 Copiado en dos gestos + deep-links `#dec-N`
- 🔢 Conversores binario / octal / decimal / hexadecimal
- 🍪 Una sola cookie propia, sin trackers ni analytics

Vívela aquí: **https://eldiablo45.github.io/RadixRef/**
